# VAPT checklist
- Step 1: scope and rules of engagement, agreed in writing before any testing.
- Step 2: reconnaissance and information gathering.
- Step 3: scanning and enumeration, for example with Nmap.
- Step 4: vulnerability analysis and manual testing, for example with Burp Suite.
- Step 5: exploitation, only within the agreed scope.
- Step 6: report with severity ratings and clear remediation steps.
- The OWASP Top 10 is the standard checklist for web application risks.
