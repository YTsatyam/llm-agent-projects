# Networking notes
- The OSI model has 7 layers: physical, data link, network, transport, session, presentation, application.
- TCP is reliable and connection-oriented; UDP is faster but has no delivery guarantee.
- A /24 subnet has 256 addresses, of which 254 are usable for hosts.
- DNS translates domain names into IP addresses.
- A switch works at layer 2; a router works at layer 3.
